# Dvizhukha

**Dvizhukha** — развлекательный Minecraft-мод с сатирической тематикой и элементами военной стилизации.

> **Тематика:** пророссийский мод, основанный на тематике СВО (Специальная военная операция, 2022–н.в.).

## Описание

Мод добавляет в игру сущность `khokhol` и автоматический цикл её появления. По задумке мода, рядом со случайным игроком периодически возникает молния, после чего через короткую задержку появляется враждебная сущность, которая выбирает этого игрока своей целью.

Мод реализован для Fabric и использует серверные события и регистрацию сущностей.

## Возможности

- Добавление кастомной сущности `khokhol`.
- Автоматический запуск цикла появления сущности через серверные тики.
- Выбор случайного игрока на сервере в качестве цели события.
- Удар молнии рядом с выбранным игроком.
- Появление сущности примерно через 1 секунду после удара молнии.
- Команда `/khokhol` для ручного запуска события.
- В одиночной игре команда доступна без проверки OP.
- На выделенном сервере запуск команды разрешён операторам.
- Сущность сохраняется в мире и получает выбранного игрока в качестве цели.

## Команда

```text
/khokhol
```

Запускает цикл появления сущности вручную.

### Права

- **Одиночная игра:** команда доступна всем.
- **Выделенный сервер:** требуется статус оператора (OP).
- **Консоль сервера:** команда также может быть запущена.

## Как работает событие

1. Мод отслеживает серверные тики.
2. После достижения заданного интервала выбирается случайный живой игрок.
3. Рядом с игроком создаётся молния.
4. Примерно через 1 секунду рядом с игроком создаётся сущность.
5. Сущность становится постоянной и получает выбранного игрока в качестве цели.

В текущей реализации интервал задан константой `SPAWN_INTERVAL = 6000`.

> **Примечание:** комментарий в исходном коде помечает этот интервал как тестовый. Фактическая длительность зависит от частоты серверных тиков Minecraft. Так же нужен [Fabric API](https://modrinth.com/mod/fabric-api).

## Техническая информация

- **Mod ID:** `dvizhukha`
- **Пакет:** `ru.florestdev.dvizhukha`
- **Загрузчик:** Fabric
- **Основной класс:** `Dvizhukha`
- **Добавляемая сущность:** `khokhol`
- **Группа сущности:** `CREATURE`
- **Размер сущности:** `1.5 × 1.5`
- **Масштаб создаваемой сущности:** `1.5`

Основной класс мода реализует `ModInitializer`, регистрирует сущность через Minecraft Registry, подключает обработчик окончания серверного тика и регистрирует команду `/khokhol`.
